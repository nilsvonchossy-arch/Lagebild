# Lagebild

Tägliches News-Update als TikTok-Ersatz: animierter Globus, Sprecherstimme mit Untertiteln, eigene Themen. Läuft als Web-App (PWA) auf dem iPad.

- `src/` – die App (Vite + TypeScript)
- `public/demo/` – Demo-Update mit den Prototyp-Meldungen vom 27.10.2026
- `tests/` – Unit-Tests (Vitest)
- `docs/prototyp.html` – ursprünglicher Prototyp aus dem Claude-Chat
- `docs/stilanalyse.md` – Analyse der Vorbild-Videos (Conflictly, Netwatch Global)
- `CLAUDE.md` – Stand, Entscheidungen, Regeln und Datenschema

Entwicklung: `npm install`, dann `npm run dev`. Prüfen: `npm run typecheck && npm test && npm run build`.
